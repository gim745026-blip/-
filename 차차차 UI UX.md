# 차차차 UI/UX Design Skill Package

---

## 🎨 Color & Tone System

- **Primary Palette**: Unified blue monotone palette using soft pastel blues and neutral grays.
- **Allowed Colors**:
  - `#0044CC` – Deep primary blue (brand accent)
  - `#6AA9FF` – Soft pastel blue (background & highlights)
  - `#A6C8FF` – Lighter pastel for subtle UI states
  - `#E0E4EB` – Neutral gray (borders, dividers, disabled state)
- **Strict Rule**: No multi‑colored primary dots, rainbow accents, or visual noise. All UI elements must draw from the list above.

---

## 🌀 Interaction & Motion Guidelines

- **Landing Page Logo Animation**:
  - On page load, the logo performs a **single quick 3‑D Y‑axis rotation** (like a spinning coin or top).
  - Duration: **≈0.6 s** with ease‑out easing.
  - After the animation finishes, the logo **remains completely static**—no looping or secondary motion.
- **General Motion**: Keep micro‑interactions minimal; use subtle fade or scale only when necessary for state feedback.

---

## 🧩 Component & Typography Standards

- **Text Wrapping**: Enforce **single‑line text wrapping**; long titles should truncate with an ellipsis (`…`).
- **Badges / Tags**: Replace colored dots with **modern subtle badges**:
  - Use the same pastel blue background with white text.
  - Example: `<Badge variant="subtle">Pending</Badge>`
- **Icons**:
  - Use **high‑contrast icons** (white or dark gray) on blue‑background buttons.
  - Crown icon example: white crown on `#0044CC` button.
- **Typography**:
  - **Font family**: `Inter`, `Helvetica Neue`, or system sans‑serif.
  - **Headings**: `font-weight: 600`, line‑height 1.2, letter‑spacing -0.02em.
  - **Body**: `font-weight: 400`, line‑height 1.5, size 14‑16 px.

---

## ✍️ UX Writing (Microcopy) Principles

- Use **professional financial terminology**:
  - "내 부담 금액" instead of informal phrasing.
  - "정산 내역", "총 결제 금액", "분담 비율" for labels.
- Keep copy **clear, concise, and action‑oriented**.
- All helper text should be placed **below inputs** in a smaller, gray‑tone font (`#6A6A6A`).
